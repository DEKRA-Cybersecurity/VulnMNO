# Tech stack (locked)

These choices are fixed for phase 1. Changing any of them is a workspace-level decision, not a stage-level decision.

## Backend

| Concern | Choice | Notes |
| --- | --- | --- |
| Language | Python 3.12+ | |
| Web framework | FastAPI ≥ 0.110 | Async; first-class Pydantic v2; native OpenAPI 3.1. |
| ORM | SQLAlchemy 2.x (async) | Use the 2.0 declarative + `async_session` style. |
| Migrations | Alembic | Generated migrations checked into the repo. |
| Validation / schemas | Pydantic v2 | Single schema definition reused by FastAPI and OpenAPI export. |
| Auth | OAuth2 password + JWT (HS256) | Refresh tokens stored hashed. OTP endpoint per §12.1. |
| Server | Uvicorn (dev) / Gunicorn + Uvicorn workers (prod) | |
| Database | SQLite (dev), PostgreSQL-compatible (prod) | Use `async-postgres` driver `asyncpg` for prod. |
| Testing | pytest + pytest-asyncio + httpx.AsyncClient | |
| Lint / format | ruff + ruff-format | |
| Type checking | mypy (strict on `app/`) | |
| Dependency mgmt | `pyproject.toml` + `uv` (or `pip` fallback) | |

## Shared

| Concern | Choice | Notes |
| --- | --- | --- |
| API contract format | OpenAPI 3.1 (YAML) | Generated by FastAPI; committed under `stages/02_api_contract/output/openapi.yaml`. |
| Mobile DTO generation | `openapi-generator` (Kotlin client) or hand-written + linted against the spec — decide in stage 05 | |
| Currency | EUR | Matches example payloads in `docs/VulnMNO.md` §13. |
| Datetime | ISO 8601 UTC strings (`2026-05-26T10:30:00Z`) | Matches §13 examples. |
| ID format in payloads | Prefixed string (`CUST-10001`, `PUR-90001`, …) | Matches §13 examples. Do not invent integer IDs in the API. |

## Out of scope for phase 1

- Push notifications (FCM): stub the registration endpoint, do not implement delivery.
- Real payment gateway: simulate top-ups and refunds with deterministic test data.
- Real provisioning system: log the provisioning event, do not call out.
- Internationalization: strings in English; locale plumbing OK but no translations.
