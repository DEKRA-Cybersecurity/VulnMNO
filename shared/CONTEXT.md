# shared — Layer 3 routing

This folder holds reference material that is **shared across all stages** (in contrast to `_config/`, which holds formatting and scoring rules).

## Files

- [glossary.md](glossary.md) — canonical names for VulnMNO components, actors and data entities. Stages cite components by these names.
- [source-pointer.md](source-pointer.md) — section-level pointers into [../docs/VulnMNO.md](../docs/VulnMNO.md). Use this to find the right section of the source instead of re-reading the whole document.

## When to edit

`glossary.md` only changes when [../docs/VulnMNO.md](../docs/VulnMNO.md) changes. `source-pointer.md` only changes when section numbering in the source changes.
